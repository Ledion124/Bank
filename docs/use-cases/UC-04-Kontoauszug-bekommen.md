| Systemanwendungsfallbeschreiben |                                                                                                                                                                                        |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Name                            | Kontoauszug                                                                                                                                                                            |
| Kurzbeschreibung                | Ein Kunde erhält am Bankschalter einen Ausdruck der Bewegungen seines Kontos.                                                                                                         |
| Akteure                         | Kunde, Bankmitarbeiter                                                                                                                                                                 |
| Auslöser                       | Der Kunde fordert am Schalter einen Kontoauszug an.                                                                                                                                    |
| Ergebnisse                      | Der Kunde erhält einen gedruckten Kontoauszug.                                                                                                                                        |
| Vorbedingung                    | Das Konto existiert; der Kunde ist legitimiert.                                                                                                                                        |
| Nachbedingung                   | Der Kontoauszug wurde dem Kunden ausgehändigt.                                                                                                                                        |
| eingehende Daten                | Kontonummer, gewünschter Zeitraum                                                                                                                                                     |
| essenzieller Ablauf             | 1.Kunde fordert Kontoauszug an und nennt Zeitraum.<br />2. Mitarbeiter ruft die Kontobewegungen im System ab.<br />3. Auszug wird gedruckt.<br />4. Auszug wird dem Kunden übergeben. |
| Offene Punkte                   | Standardzeitraum und Format des Auszugs sind nicht spezifiziert.                                                                                                                       |
| Änderungshistorie              | Erstversion.                                                                                                                                                                           |
| Sonstiges                       | -                                                                                                                                                                                      |
| Anmerkungen                     | Dieser Anwendungsfall steht in keiner «includes»-Beziehung; er ist eigenständig.                                                                                                    |
