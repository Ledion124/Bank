| Systemanwendungsfallbeschreiben |                                                                                                                                                                                                                                                     |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Name                            | Einzahlung                                                                                                                                                                                                                                          |
| Kurzbeschreibung                | Ein Kunde zahlt am Bankschalter Bargeld oder einen Scheck auf sein Konto ein.                                                                                                                                                                       |
| Akteure                         | Kunde, Bankmitarbeiter                                                                                                                                                                                                                              |
| Auslöser                       | Der Kunde möchte einen Betrag auf sein Konto einzahlen.                                                                                                                                                                                            |
| Ergebnisse                      | Der Kontostand ist um den Einzahlungsbetrag erhöht; der Kunde erhält eine Quittung.                                                                                                                                                               |
| Vorbedingung                    | Das Zielkonto existiert und ist aktiv.                                                                                                                                                                                                              |
| Nachbedingung                   | Der Kontostand ist aktualisiert; eine Quittung wurde ausgestellt und dem Kunden übergeben.                                                                                                                                                         |
| eingehende Daten                | Kontonummer, Einzahlungsbetrag, Zahlungsmittel (Bargeld oder Scheck)                                                                                                                                                                                |
| essenzieller Ablauf             | 1. Kunde nennt Kontonummer und übergibt Geld bzw. Scheck.<br />2. Mitarbeiter erfasst den Betrag im System.<br />3. Kontostand wird aktualisiert.<br />4. Quittung wird erstellt (includes Quittung).<br />5. Quittung wird dem Kunden übergeben. |
| Offene Punkte                   | Obergrenze für Bareinzahlungen ohne zusätzliche Prüfung (z. B. Geldwäscheprävention) ist offen.                                                                                                                                                |
| Änderungshistorie              | Erstversion.                                                                                                                                                                                                                                        |
| Sonstiges                       | -                                                                                                                                                                                                                                                   |
| Anmerkungen                     | Der Anwendungsfall steht in einer «includes»-Beziehung zum Anwendungsfall*Quittung* .                                                                                                                                                           |
