| Systemanwendungsfallbeschreiben |                                                                                                                                                                                                                                                     |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Name                            | Auszahlung                                                                                                                                                                                                                                          |
| Kurzbeschreibung                | Ein Kunde hebt am Bankschalter Bargeld von seinem Konto ab.                                                                                                                                                                                         |
| Akteure                         | Kunde, Bankmitarbeiter                                                                                                                                                                                                                              |
| Auslöser                       | Der Kunde möchte einen Betrag von seinem Konto abheben.                                                                                                                                                                                            |
| Ergebnisse                      | Der Kontostand ist um den Auszahlungsbetrag reduziert; der Kunde erhält das Bargeld sowie eine Quittung.                                                                                                                                           |
| Vorbedingung                    | Das Konto existiert und weist ein ausreichendes Guthaben bzw. einen ausreichenden Kreditrahmen auf; der Kunde ist legitimiert.                                                                                                                      |
| Nachbedingung                   | Der Kontostand ist aktualisiert; das Bargeld wurde ausgezahlt; eine Quittung wurde ausgestellt.                                                                                                                                                     |
| eingehende Daten                | Kontonummer, gewünschter Auszahlungsbetrag, Legitimation des Kunden                                                                                                                                                                                |
| essenzieller Ablauf             | 1.Kunde stellt den Auszahlungswunsch und legitimiert sich.<br />2. Mitarbeiter prüft Guthaben und Legitimation.<br />3. Betrag wird vom Konto abgebucht.<br />4. Bargeld wird ausgezahlt.<br /><br />5. Quittung wird erstellt (includes Quittung) |
| Offene Punkte                   | Maximalbetrag pro Auszahlung am Schalter ist nicht spezifiziert.                                                                                                                                                                                    |
| Änderungshistorie              | Erstversion.                                                                                                                                                                                                                                        |
| Sonstiges                       | -                                                                                                                                                                                                                                                   |
| Anmerkungen                     | Der Anwendungsfall steht in einer «includes»-Beziehung zum Anwendungsfall *Quittung*.                                                                                                                                                          |
