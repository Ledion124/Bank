| Systemanwendungsfallbeschreiben |                                                                                                                                                                                                                                                                                         |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Name                            | Konto eröffnung                                                                                                                                                                                                                                                                        |
| Kurzbeschreibung                | Ein Kunde eröffnet am Bankschalter ein neues Konto. Der Bankmitarbeiter erfasst die persönlichen Daten des Kunden, prüft die erforderlichen Dokumente und legt das Konto im Bankensystem an.                                                                                         |
| Akteure                         | Kunde, Bankmitarbeiter (Schalterpersonal)                                                                                                                                                                                                                                               |
| Auslöser                       | Der Kunde äußert am Schalter den Wunsch, ein neues Konto zu eröffnen.                                                                                                                                                                                                                |
| Ergebnisse                      | Ein neues Konto ist im Bankensystem angelegt; der Kunde erhält Kontonummer und Kontounterlagen.                                                                                                                                                                                        |
| Vorbedingung                    | Der Kunde kann sich mit einem gültigen Ausweisdokument legitimieren; ein Bankmitarbeiter ist am Schalter verfügbar.                                                                                                                                                                   |
| Nachbedingung                   | Das Konto ist aktiv und im System gespeichert; die eingereichten Dokumente sind geprüft und archiviert.                                                                                                                                                                                |
| eingehende Daten                | Persönliche Daten (Name, Adresse, Geburtsdatum), Ausweisdokument, gewünschter Kontotyp                                                                                                                                                                                                |
| essenzieller Ablauf             | 1. Kunde äußert Wunsch zur Kontoeröffnung.<br />2. Mitarbeiter erfasst die Kundendaten.<br />3. Prüfung der eingereichten Dokumente (includes Dokumente).<br />4. Auswahl des Kontotyps.<br />5. Anlegen des Kontos im System.<br />6. Übergabe der Kontounterlagen an den Kunden. |
| Offene Punkte                   | Art und Umfang einer Bonitäts-/Identitätsprüfung sind noch nicht spezifiziert.                                                                                                                                                                                                       |
| Änderungshistorie              | Erstversion.                                                                                                                                                                                                                                                                            |
| Sonstiges                       | -                                                                                                                                                                                                                                                                                       |
| Anmerkungen                     | Der Anwendungsfall steht in einer «includes»-Beziehung zum Anwendungsfall *Dokumente* .                                                                                                                                                                                            |
